# 工数管理タイマー（Chrome拡張機能）

ユーザー別・日付別で工数を管理する軽量Chrome拡張機能です。

## 機能

- 工数タイマー（開始 / 一時停止 / 完了）
- 案件名・工数名のマスタ管理
- 並列タスク対応（比率配分）
- TSV / HTMLコピー（Excel貼り付け対応）
- 0.5時間単位での表示
- chrome.storage.local によるデータ保存

## ローカルへの導入手順

### 1. リポジトリをクローン

```bash
git clone https://github.com/Dicky1114/time-management-extension.git
```

### 2. Chromeに拡張機能を読み込む

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をONにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. クローンした `time-management-extension` フォルダを選択
5. ツールバーに拡張機能アイコンが表示される

### 3. 使い方

1. ツールバーの拡張機能アイコンをクリック
2. 担当者名を入力（自動保存されます）
3. 「マスタ」タブで案件名・工数名を登録
4. 「新規」タブで工数を追加し、タイマーで計測
5. 「完了」タブからExcel向けにコピー可能
